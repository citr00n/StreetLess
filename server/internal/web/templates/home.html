How it works

  1. Install

    Get the app from the operator and place it on your SD card in 3ds/streetless/. Create an account and pair your console using a QR code or one-time code in your account.

  2. Choose your circle

    Stay in the public lobby or exchange with confirmed friends and invite-only rooms.

  3. Press Sync

    Only Sync in the app sends game data and downloads queued passes for your games.

Public lobby

Random exchange is enabled by default. You can receive up to three new game slots in a rolling 24-hour period.

Private mode

Disables random exchange in both directions. Confirmed friendships and room memberships remain intact.

Friends and rooms

Add friends by code and invite them to rooms. Both participants must enable exchange for the selected route.
